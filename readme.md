# 🤖 AI Spy Robot

An Arduino-based robotic surveillance project designed for remote monitoring and movement control. The robot uses an ESP32-CAM for camera-based monitoring and a NodeMCU for controlling the robotic system.

## 🚀 Features

* Camera-based remote monitoring using ESP32-CAM
* Wireless robotic control
* Four-wheel movement
* Three-servo mechanism
* Motor driver based motor control
* Compact robotic surveillance platform

## 🛠️ Hardware Used

* ESP32-CAM
* NodeMCU
* Motor Driver
* 4 × DC Motors
* 3 × Servo Motors
* Robot Chassis
* Battery/Power Supply
* Jumper Wires

## 💻 Software & Tools

* Arduino IDE
* Embedded C/C++
* ESP32 Board Support
* NodeMCU Board Support

## ⚙️ Working

The **NodeMCU** is used for controlling the robotic movement and connected components. The **motor driver** controls the four DC motors, allowing the robot to move in different directions.

The **ESP32-CAM** provides camera-based monitoring, allowing the robot to be used as a remote surveillance platform.

Three servo motors are used as part of the robotic mechanism according to the project's hardware configuration.

## 🔧 Setup

1. Install Arduino IDE.
2. Install the required board packages for ESP32 and NodeMCU.
3. Connect the hardware according to the circuit configuration.
4. Open the Arduino `.ino` files.
5. Select the correct board and COM port.
6. Upload the respective code.
7. Power the robot using the appropriate power supply.
8. Start the robot and use the implemented control mechanism.
